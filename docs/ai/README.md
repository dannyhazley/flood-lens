# Transparent AI use

FloodLens uses AI as a disclosed tutor, implementation partner and reviewer. The maintainer owns decisions and verification. This directory contains [roles](ROLES.md), [learning records](learning-log.md), [Jira rules](JIRA.md) and [source attribution](SOURCES.md).

Real evidence is a bounded requirement, observed code/experiment output, meaningful checks and the maintainer's actual explanation. No “AI-written percentage”, human-understanding certificate or commercial-value claim is inferred from a green check.
