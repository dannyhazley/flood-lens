# Start without overwriting your project

1. Read the project README and check actual files/Git status.
2. Review the repository's agent instructions and skills; they guide work but do not replace the project ticket or checkpoint.
3. Ask `$floodlens-guide` to inspect this repository, connected Jira resources and current checkpoint, then draft one bounded C0 ticket. Ticket creation requires your instruction and chosen project. `LOCAL-1` is only a labelled local draft until Jira has a real key.
4. Ask `$floodlens-tutor` for one C0 concept/unit. It should explain API/input/output, invite a prediction/attempt, verify and record actual learning. Pair/delegate mode is available when you request it.
5. Follow [C0](checkpoints/C0.md): repository/environment, meaningful checks and CI from the start.
6. End with a concrete artifact/blocker, progress/state and next task. Do not jump to training/UI before their gates.

Example first prompt: “Use $floodlens-guide to inspect this repository and current progress. We are before C0. Use my connected Jira read-only to discover the personal project choices; draft one session-sized setup ticket, without creating it yet. Then explain how I start the first teaching unit.”
